# Lumiere

App Android para registrar e avaliar os filmes que você já assistiu.

## Funcionalidades
- Filmes populares e busca por título
- Detalhes do filme com sinopse e elenco
- Marcar como "Já vi", "Quero ver" e "Favorito", com nota em estrelas
- Perfil com estatísticas

## Tecnologias
Kotlin · XML · ViewBinding · MVVM · Navigation Component · Retrofit · Room · Coroutines/Flow · Glide

## Como rodar
1. Crie uma chave de API no TMDB
2. Adicione `TMDB_API_KEY=sua_chave` ao arquivo `local.properties`
3. Rode o app pelo Android Studio

## Créditos
This product uses the TMDB API but is not endorsed or certified by TMDB.
